# Income Tax Calculator (Java Swing)

## Overview

Income Tax Calculator is a Java Swing-based desktop application that calculates income tax based on the user's age and annual salary. The application provides a simple graphical user interface (GUI) for entering personal details and displays the applicable tax slab and calculated tax amount.

## Features

* User-friendly graphical interface built with Java Swing
* Calculates income tax based on age-specific tax slabs
* Supports different age categories:

  * Below 60 years
  * 60 to 80 years
  * Above 80 years

* Displays:

  * Name
  * Aadhaar Number
  * Gender
  * Age
  * Salary
  * Tax Slab
  * Calculated Income Tax
* Error handling for invalid inputs

## Technologies Used

* Java
* Java Swing
* AWT
